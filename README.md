# 响度归一与增益平滑（从 0 实现）

起始环境只有这份说明、`samples/**` 与 `.gitignore`，实现、页面与测试都要新写。Python 3.13、只用标准库，
无构建、无网络。现场是一批四十条、合计几小时的素材，响度差十几分贝。交付物在仓库根：`lucidgain.py`
（库 + 命令行入口）、`web/index.html`（原生 HTML + Canvas）、`unittest` 测试（只读 `samples/**`）。

## 一、范围

```text
python3 lucidgain.py run --input <文件或目录>… --out <目录>
```

做：测出整段的门控响度；算一条逐帧增益曲线；应用到样本上；每个输入写处理后的 WAV 与逐帧增益 CSV，
汇总 `report.json`（缺省 `out/`，不入库）。库接口 `measure(路径)`、`render(路径, 输出目录)` 与
命令行共用口径。页面叠画原始与处理后的波形，下面画逐帧增益曲线，标出触顶与静音位置，数字取自引擎输出。

不做：压缩器与限幅器、多段均衡、降噪、重采样、多声道与非 16 位、非 PCM 与压缩格式、实时采集、并行与
持久化。页面不引 CDN、字体、图片与网络请求，也不重算响度、增益与静音段。

## 二、口径与公式

**帧**：窗口 `W = 400 ms`、步进 `H = 100 ms`。设采样率 `R`、总采样数 `S`，帧 n（从 0 起）覆盖
`[n·Hs, n·Hs + Ws)`，`Ws = round(W·R/1000)`、`Hs = round(H·R/1000)`；帧数
`N = max(1, ⌊(S − Ws)/Hs⌋ + 1)`，`S < Ws` 时整段算一帧。

**幅度与门控**：采样 x 为 int16，`a = x/32768`（`x = −32768` 记 `a = −1`）；帧内各采样等权，不做心理
声学加权。帧功率 `P[n] = mean(a²)`，帧响度 `L[n] = max(−120, 10·log10 P[n])`（dBFS）。
`L[n] ≥ −60 dBFS` 的帧参与测量，其余帧称为静音帧；`L_meas = 10·log10(参与帧 P 的算术平均)`，
一帧都没有时记 −120 dBFS。

**增益**：目标 `L_target = −20 dBFS`，允许误差 ±1.0 dB。基础增益 `G = L_target − L_meas` 限制在
`[−18, +18] dB`（下限 −18、上限 +18）；静音帧的目标增益取 `min(G, 0)`，其余帧取 `G`。

**平滑**：一阶指数平滑，`τ = 200 ms`，`α = 1 − e^(−H/τ) ≈ 0.393469`。`s[0] = g[0]`，此后
`s[n] = clamp(s[n−1] + α·(g[n] − s[n−1]), s[n−1] ± 1.5)` 再限制到 `[−18, +18] dB`：相邻帧步进
≤ 1.5 dB/帧，整段只有这一条曲线，不许逐段重算。

**权威区间与静音区间**：帧 n 的权威区间是 `[n·Hs, (n+1)·Hs)`，最后一帧延伸到文件末尾；
连续 ≥ 5 个静音帧合成一段静音区间，起止按权威区间取。

**应用与越界**：采样 i 落在帧 n 的权威区间时，增益在 dB 域线性插值到下一帧：
`G(i) = s[n] + (s[n+1] − s[n])·(i − n·Hs)/Hs`；最后一帧与文件末尾的尾巴都用 `s[N−1]`。
`y(i) = round(x(i)·10^(G(i)/20))`（四舍五入，.5 远离零）再限制到峰值上限
`±29205 = ±round(32768·10^(−1/20))`（−1.0 dBFS），越界的采样计入 `clipped_samples`。
静音区间里的采样在限幅前先取 `G(i) = min(G(i), 0)`：静音不许放大，区间起点允许一次向下的跳变，不计入步进。

## 三、状态机与数据结构

```text
读 WAV → 逐帧 P、L → 静音帧 → L_meas → G → g[n] → 平滑 + 步进 → s[n] → 静音区间 → 逐采样增益 → 限幅
```

`P`、`L`、`silent` 等长，下标即帧号；`Hs` 是唯一的时间换算系数。曲线 `s[0..N−1]` 相邻差 ≤ 1.5 dB，
静音帧上朝 0 dB 收敛但不强制为 0。

## 四、输入输出与文件格式

**4.1 输入 WAV**：RIFF/WAVE 的 PCM（format 1）、单声道、16 位小端、`block_align = 2`、任意采样率
（样例都是 16000 Hz）。头部可能夹 `LIST`/`INFO` 等附加块，要按块扫描定位 `fmt` 与 `data`；`data` 长度
不符算损坏。目录输入不递归、只取 `*.wav`，同一路径只算一次。

**4.2 增益曲线 `<名>.gain.csv`**：UTF-8、`\n`、末行有换行，表头 `frame,start_ms,gain_db,silent`，
每帧一行，`start_ms = n·H`，`gain_db` 保留 3 位小数，`silent` 取 `0|1`；处理样本用的就是这份曲线的值。

**4.3 处理后样本 `<名>.wav`**：与输入同采样率、单声道、16 位 PCM。

**4.4 汇总 `report.json`**：UTF-8、缩进 2 空格，顶层是 `{"version":1,"files":[…记录…]}`，`files` 按
`file` 的码点升序。每条记录的键序：`file`、`sample_rate`、`samples`、`frames`、`meas_loudness_dbfs`、
`target_dbfs`、`gain_base_db`、`gain_min_db`、`gain_max_db`、`gain_mean_db`、`max_step_db`、
`silent_frames`、`silent_ranges_ms`、`clipped_samples`、`peak_in`、`peak_out`、
`achieved_loudness_dbfs`、`target_met`。dB 字段保留 2 位小数（.5 远离零），`silent_ranges_ms` 是半开
毫秒端点、按起点升序；`peak_*` 是采样绝对值最大值（`−32768` 记 32768），`achieved_loudness_dbfs` 用同一
口径测处理后的样本，`target_met` 表示该值与 −20 dBFS 的差 ≤ 1.0 dB。

**4.5 命令行**：参数不对、打不开、格式不支持或损坏时，向 stderr 打一行 `error: <文件名>: <原因>`，
该文件不进报告，退出码 2；成功 0。

**4.6 页面**：`python3 -m http.server 8000` 从仓库根起服务，打开 `http://127.0.0.1:8000/web/`。顶部是 out
目录输入框（默认 `../out`）与加载按钮；每个文件一块 `<canvas class="scope" data-file="<名>">`：上半叠画
原始与处理后的波形，下半画逐帧增益曲线（横轴时长、纵轴 −18…+18 dB），静音画灰带、触顶画红带，
旁边写响度达成与峰值。图形与数字只能来自 `report.json`、`gain.csv` 与两份 WAV。

## 五、性能与验收口径

预算（Python 3.13、单线程、冷启动计入）：3 小时 16 kHz 单声道（约 1.7 亿采样）端到端 ≤ 180 s，
峰值内存 ≤ 256 MiB 且不随时长增长；`samples/audio` 单个 ≤ 1 s。

1. **环境**：Python 3.13+、只用标准库；无构建、无网络、无第三方依赖；命令在仓库根直接跑。
2. **逐条核对**：每个样例的记录与 `samples/expected/<名>.txt` 对上，容差写在该文件头。
3. **结构不变量**：`s[n] ∈ [−18, +18]`；相邻帧步进 ≤ 1.5 dB；静音区间里逐采样增益 ≤ 0 dB；`peak_out ≤ 29205`；
   `achieved_loudness_dbfs` 与目标差 ≤ 1.0 dB（写 `target_met: no` 的那条按它给的达成值核对）。
4. **确定性**：同一素材跑两遍（可换 `PYTHONHASHSEED`），`report.json`、`gain.csv` 与输出 WAV 逐字节相同。
5. **页面**：数字与图形来自引擎输出；手改 `report.json`、`gain.csv` 后刷新，画面跟着变；无外部引用、控制台无报错。
6. **不许写死**：不得读 `samples/expected/**` 参与计算，不得按文件名、时长或样例数特判；验收会换素材。
7. **测试**：`python3 -m unittest` 通过，用例只读 `samples/**`、只用标准库。

## 六、样例说明

`samples/audio/<名>.wav` 与 `samples/expected/<名>.txt` 同名一一对应，都是 16000 Hz、16 位、单声道。

| 文件 | 场景 | 盯的是什么 |
| --- | --- | --- |
| `soft_passage.wav` | 整体偏轻 | 正增益约 +12 dB，峰值离上限还远 |
| `hot_take.wav` | 整体偏响 | 要衰减，处理后不顶上限 |
| `swings.wav` | 忽大忽小 | 段间差 20 dB，只有一条曲线 |
