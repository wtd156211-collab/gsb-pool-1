# 重复模板折叠与还原（从 0 实现）

写一个只用 Python 3.13 标准库的命令行工具：把成批日志折成「模板 + 槽值」，能逐字节还原原文，并生成模板清单、统计和一份可直接打开的静态报告（原生 HTML + 内联 SVG，无构建、无外部资源）。输入按字节处理。

## 一、范围

做：入口 `python -m logfold`，子命令 `fold` / `restore` / `report`；产出模板清单、折叠文件、统计 JSON、报告 HTML 与还原目录。

不做：不改动输入；不联网、不读写数据库；不解析 JSON 或时间语义；不做多线程/多进程；不跨运行增量学习（每次 `fold` 从空模板库开始）；报告不得出现 `http://`、`https://`、`<link`、`<script src`。

## 二、口径与公式

**记录**：按 `\n` 切行，行内容不含行尾 `\n`（`\r` 保留）。首行开一条记录；**以空白字节（0x20/09/0B/0C/0D）开头的行并入上一条记录**，行间 `\n` 属记录内容；当前记录已达 1 MiB 时续行另起一条。空行是内容为空的独立记录。记录的「末尾换行标记」= 其最后一行是否带 `\n`。

**token**：把记录内容切成铺满全部字节的序列。

- 连续空白字节（0x20/09/0B/0C/0D/0A）→ 空白 token，非变量。
- 其余是字段。字段整段命中下面任一条，或长度 > 1024 字节 → 整段是一个槽 token；否则按 `[0-9A-Za-z_]+` 与其它单字节切开，切出的标识串再判变量。
- 整字段规则：`[0-9]+`；`[0-9]+\.[0-9]+`；`0[xX][0-9A-Fa-f]+`；长度 ≥ 16 的十六进制串；UUID；IPv4；`[0-9]{4}-[0-9]{2}-[0-9]{2}([T ][0-9]{2}:[0-9]{2}:[0-9]{2}(\.[0-9]+)?(Z|[+-][0-9]{2}:?[0-9]{2})?)?`。
- 标识串规则：`[0-9]+`；`0[xX][0-9A-Fa-f]+`；长度 ≥ 8 的十六进制串；长度 ≥ 3 且同时含字母与数字。
- 一条记录最多保留前 **1024** 个 token；若其后还有字节，把第 1025 个 token 起至记录末尾的字节并为**一个**尾部槽 token（故 token 数 ≤ 1025）。

**模板与相似度**：模板是等长的格子序列，每格为字面量（原始字节）或槽。

- 只与 token 数相同的模板比较；相似度 = 记录与模板在**字面量格**上一致的格数 ÷ 该模板字面量格数，模板没有字面量格时记 1。
- 取相似度最高的模板，**并列取模板号最小者**；相似度 ≥ **0.7** 即并入：把不一致的字面量格改成槽，次数 +1。
- 否则新建模板，以该记录的变量判定结果作为初始槽；模板号从 **0** 起按新建顺序递增。

**上限**：模板总数上限 **512**。需要新建且已达上限时，若存在同长度模板就强制并入相似度最高者（并列取最小模板号），否则允许超限新建并在 stderr 输出含 `TEMPLATE_CAP` 的一行。

**排序**：模板清单按次数降序，次数相同按模板号升序。

**压缩率**：`(全部折叠文件字节数 + 模板清单字节数) ÷ 输入字节总和`，四舍五入保留 4 位小数。门槛 **≤ 0.85**，超过则 `fold` 退出码 3 且在 stderr 输出 `RATIO_EXCEEDED`。

**还原**：`restore` 的每个输出必须与对应输入**逐字节相同**（`\r`、行尾 `\n` 有无、空行、多行记录都不能差）。

## 三、处理流程与数据结构

`fold` 跑两遍，中间态只允许存「一条记录一个模板号」这类派生数据，禁止整份拷贝原文，结束时清空 `var/tmp/`。

1. 第一遍按输入顺序逐条记录：切 token → 判变量 → 比相似度 → 并入或新建 → 追加模板号；模板库只留「格子序列 + 次数」。
2. 定稿后槽集合不再变化；第二遍重读输入，按**最终**结构写折叠文件（只写槽位的值，字面量留在模板里）。
3. 写 `stats.json`，按门槛定退出码。

字段长度、token 数与尾部槽上限共同保证内存只与模板库和单条记录有关。

## 四、输入输出与文件格式

```
python -m logfold fold    --out var <文件或目录>...
python -m logfold restore --var var [--out var/restore]
python -m logfold report  --var var
```

输入可以是文件或目录；目录展开为其中按文件名（UTF-8 字节序）升序的文件，不递归；多个输入同名按错误处理。`<name>` 指输入文件 basename。

```
var/templates.tsv      模板清单
var/fold/<name>.fold   折叠文件
var/stats.json         统计
var/report.html        报告
var/restore/<name>     还原结果
var/tmp/               中间文件，结束前清空
```

**模板清单**：每行 `<模板号>\t<次数>\t<模板文本>\n`；模板文本由各格拼接，槽写 `<*>`，字面量中的 `\`、制表、换行、回车、`<` 分别写成 `\\`、`\t`、`\n`、`\r`、`\x3c`。

**折叠文件**：每条记录一行，`<模板号>` 之后每个槽位接一个 `\t` 和转义后的值（`\`、制表、换行、回车 → `\\`、`\t`、`\n`、`\r`）。文件行尾跟随输入：输入最后一条记录带末尾换行则折叠文件以 `\n` 结尾，否则不以 `\n` 结尾。

**stats.json**：UTF-8、2 空格缩进、末尾一个 `\n`（即 `json.dumps(obj, ensure_ascii=False, indent=2) + "\n"`），键序如下：

```json
{"files": [{"name": "orders.log", "records": 12, "bytes_in": 1049, "bytes_fold": 653}], "templates": 24,
 "bytes_templates": 4037, "bytes_in": 27108, "bytes_out": 20462, "ratio": 0.7548, "ratio_limit": 0.85, "ratio_ok": true}
```

`bytes_out` = 折叠文件字节数 + 模板清单字节数。

**report.html**：UTF-8 单文件，含概览表（记录数、模板数、字节数、压缩比、门槛、判定）、按文件的四列表、内联 `<svg width="360" height="180" viewBox="0 0 360 180">` 与模板明细表。柱状图取清单前 10 个模板，基线 `y=160`，第 i 个（i 从 0 起）柱：`x=40+32i`、宽 24、高 `⌊次数×120÷最大次数+0.5⌋`、`y=160−高`，柱上方标模板号；明细表顺序与清单一致，文本按 HTML 转义。同一输入两次运行，`var/` 下产物必须逐字节一致（不写时间戳、随机数、绝对路径）。

## 五、性能与验收口径

- 单线程流式：2 GiB 输入峰值常驻内存 ≤ 512 MiB，64 MiB 与 2 GiB 的峰值差 ≤ 32 MiB（`/usr/bin/time -v`）。
- 吞吐：输入 ≥ 512 MiB 时 `fold` ≥ 8 MiB/s、`restore` ≥ 20 MiB/s（3 次中位数）。
- 还原：每个输入的还原结果与原文 `sha256` 相同。
- 门槛与样例：在样例上 `fold` 退出码 0、`ratio ≤ 0.85`，产物与期望结果逐条一致。
- 退出码：0 正常；1 参数或输入错误；2 产物损坏；3 压缩率超门槛。

## 六、样例说明

`samples/logs/` 5 个文件；`samples/expected/` 是「`python -m logfold fold --out var samples/logs`（文件按名升序）」一次运行的期望结果。

| 文件 | 覆盖场景 |
| --- | --- |
| orders.log | 同一模板多种变量；等级列宽不同，空白位也成了槽 |
| similar-ids.log | 变量里含相似片段；阈值两侧各有实例 |
| unique.log | 几乎每行都不一样（含一条空行），模板数接近行数 |
| stacktrace.log | 多行堆栈：续行归并成一条记录，模板含 `\n` 字面量 |
| huge-line.log | 极长行：尾部槽、超长单字段整段成槽、末行无换行 |

`templates.txt` 与 `var/templates.tsv`、`fold/<name>.fold.txt` 与 `var/fold/<name>.fold` 逐字节相同；`stats.txt` 给出记录数、字节数、压缩率与柱状图数据，可逐行核对；`samples/expected/README.md` 给出还原校验与 sha256 对照。样例不触发模板上限。
