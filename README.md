# 直方图均衡与对比度增强（从 0 实现）

仓库里只有本说明、`samples/**` 与 `.gitignore`；库、命令行入口、页面与测试都从零写，`samples/notes.md`
是现场记录，不参与判定。

## 1. 范围

交付物（仓库根，Python 3.13 标准库，无构建、无依赖）：

```text
python histeq.py <输入.bmp> <输出.bmp> [--mode global|local] [--tiles G] [--clip X.XX]
                 [--lut <csv>] [--tiles-csv <csv>] [--probe <csv>]
viewer.html      # 单文件、原生 HTML/Canvas 对照页
tests/           # unittest 用例，只读 samples/
```

做：global 整图均衡与 local 分块均衡（统计 → 限幅重分配 → 双线性插值），每通道独立；映射表与
校验点导出；离线对照页。

不做：PNG/JPEG/GIF；8/16/32 位、带调色板、RLE 或压缩的 BMP；自上而下（biHeight<0）的 BMP；
色彩转换与 ICC、色度保护；多线程、GPU、`ctypes`/`subprocess` 调外部程序；联网与外部资源；
构建与第三方依赖。非法输入不做容错——样例保证合法，遇到非法输入报错退出即可。

## 2. 口径与公式

坐标原点在左上，x 向右、y 向下，宽 W、高 H，像素中心在 (x+0.5, y+0.5)。取整统一「半值向上」：
`round(p,q) = (2p+q)//(2q)`（q>0，`//` 向下取整整除），结果一律截断到 [0,255]（记作 `clamp255`）。

**2.1 映射表**。对一张直方图 `hist[0..255]`（样本共 N 个）：`cdf[i] = Σ_{k≤i} hist[k]`，`cdf_min` 取
第一个 `hist[i] > 0` 的桶的 cdf 值，则 `lut[i] = clamp255(round(255*(cdf[i]-cdf_min), N-cdf_min))`；
只有一个非零桶（`N == cdf_min`）时规定 `lut[i] = i`（global 的样本是整幅图的某个通道，local 的是
某块某通道）。

**2.2 限幅与重分配**（只用于 local）。`--clip` 是超限系数 α（十进制、≤两位小数、0.01..10.00，
默认 2.00），A = α×100 的整数。每块每通道的阈值 `T = max(1, (A*n)//25600)`（n 是该块像素数），
按顺序做一遍：

1. `E = Σ max(0, hist[i]-T)`，同时 `hist[i] = min(hist[i], T)`；
2. `share = E//256`；share ≥ 1 时每桶 `hist[i] += share`、`E -= share*256`；
3. 剩下的 E（0 ≤ E < 256）从下标 0 起给 E 个桶各 +1；Σ hist 仍等于 n。

之后不再二次限幅（个别桶可能再次超过 T）。

**2.3 分块**。`--tiles G` 是每边块数（默认 8，取 2..32）：第 c 列块覆盖 `[c*W//G, (c+1)*W//G)`，
第 r 行块覆盖 `[r*H//G, (r+1)*H//G)`；不整除时按此式取整，最后一块可能更小，T 用该块的 n。
每块每通道先按 2.2 重分配、再按 2.1 得到一张 256 项映射表。

**2.4 双线性插值**（local 的输出）。列方向记 `X = 2x+1`：`m = (X*G)//W`，
`c0 = min(max((m-1)//2, 0), G-1)`，`c1 = min(c0+1, G-1)`，
`wc = min(max(X*G-(2*c0+1)*W, 0), 2*W)`，列权重 `wc/(2W)` 与 `(2W-wc)/(2W)`；行方向同式
（X→Y=2y+1、W→H、c→r）得 r0、r1 与行权重 `wr/(2H)`、`(2H-wr)/(2H)`。记输入值 v 在四张相邻表
（[r0][c0]、[r0][c1]、[r1][c0]、[r1][c1]）的 [ch][v] 项为 L00、L10、L01、L11，则

```text
out = clamp255(round((2W-wc)*(2H-wr)*L00 + wc*(2H-wr)*L10 + (2W-wc)*wr*L01 + wc*wr*L11, 4*W*H))
```

全程整数运算；c0 == c1 或 r0 == r1 时两张表相同。

**2.5 彩色与单调性**。R/G/B 完全独立：各自的直方图、映射表与插值；不提取亮度，不做色度保护。
每张映射表是 [0,255] 内的整数且单调非递减；global 下同一输入值的输出与位置无关；输入 R=G=B
时输出仍 R=G=B。

## 3. 数据结构与处理顺序

位图解码成 `Image(width, height, pixels)`：`pixels` 是长 3×W×H 的 `bytearray`（行优先、自顶向下、
通道 R,G,B）；映射表是 256 项整数序列，local 为 G×G×3 张。顺序：①读文件、校验头部 → ②解码
→ ③算映射表（global 三张；local 逐块 2.2→2.1）→ ④逐像素查表、按 2.4 插值、clamp255 → ⑤写 BMP
与 CSV。任一步失败都写 stderr 并非 0 退出。

## 4. 输入输出与文件格式

**4.1 命令行**。用法见第 1 节，默认 `--mode global --tiles 8 --clip 2.00`。`--lut` 只在 global 有效，
`--tiles-csv` 只在 local 有效，用错模式即报错退出；`--probe` 两种模式都能用。退出码：成功 0、
输入不合规 2、其余错误非 0。

**4.2 BMP**（未压缩）。读：只接受 `'BM'`、`biSize==40`、`bfOffBits==54`、`biPlanes==1`、
`biBitCount==24`、`biCompression==0`、`biHeight>0`；`stride = ((3W+3)//4)*4`，自下而上、每像素
B,G,R，行尾填充忽略。写：54 字节头 + 自下而上的 BGR，行填充写 0，`bfSize`、`biSizeImage` 填实际值，
其余头字段与保留字段全写 0。

**4.3 映射表 CSV**：UTF-8、无 BOM、LF、逗号分隔、有表头。global 写 `channel,in,out`（768 行，
R/G/B 各 256 行）；local 写 `tile_r,tile_c,channel,in,out`，按 r、c、channel、in 升序。不写别的列。

**4.4 校验点 CSV**（`--probe`）：表头 `mode,x,y,r_in,g_in,b_in,r_out,g_out,b_out`，`mode` 取
`global` 或 `local-g{G}-c{A}`（A 即 2.2 里的 α×100，如 `local-g8-c200`）。13 个采样点（模式顺序、
点顺序）：(0,0) (W-1,0) (0,H-1) (W-1,H-1) (W//2,H//2) (W//4,H//4) (3W//4,H//4) (W//4,3H//4)
(3W//4,3H//4) (W//2,0) (W//2,H-1) (0,H//2) (W-1,H//2)；`*_in` 取自输入图，`*_out` 按本说明算。

**4.5 页面** `viewer.html`：单文件、双击即开，不联网、不引 CDN 与外部字体。用 `<input type="file">`
或拖放载入前后两张 BMP 并排对照，支持 1×..16× 最近邻放大、拖动平移、悬停取色（坐标与 RGB）。

## 5. 性能与验收口径

1. 环境：只用标准库、单线程，命令在仓库根直接跑；无网络、无构建、无依赖。
2. 预算：样例秒级完成；2048×2048 的图在 local 默认参数下单张 ≤ 90 秒、峰值内存 ≤ 1 GiB，
   时间随像素数近似线性。
3. 确定性：同一输入与参数跑两遍，输出 BMP 逐字节相同；不依赖时间、随机数、哈希种子、区域设置与
   环境变量；除输入输出与显式 CSV 外不读写别的路径。
4. 样例：`samples/expected/` 的映射表与校验点表逐行一致；`--lut`、`--tiles-csv`、`--probe` 的输出
   与同名期望文件逐字节相同。
5. 退化图与坏输入：几乎全黑/全白/整幅一色的图不得除零、出负值或越界；非 24 位、带压缩、缺文件、
   头部不合法等给可读错误并非 0 退出，不留半个输出文件。
6. 页面与测试：离线可开、无外部资源、换图后数值跟着变；`python -m unittest` 通过（只读 `samples/`，
   只用标准库）。

## 6. 样例说明

`samples/images` 有 7 张未压缩 24 位 BMP，`samples/expected` 同名文件给出口径核对值，按 `global`、
`local --tiles 8 --clip 2.00`、`local --tiles 4 --clip 4.00` 三种参数算出。

| 文件 | 尺寸 | 场景 |
| --- | --- | --- |
| `dark.bmp` | 160×120 | 整体偏暗（20..84），前景略亮 |
| `bright.bmp` | 160×120 | 整体偏亮（161..244） |
| `clean.bg.bmp` | 160×120 | 背景干净：均匀大背景 + 纯色前景 |
| `noisy.bg.bmp` | 160×120 | 背景有细颗粒噪声（±12），前景干净 |
| `near_black.bmp` | 64×48 | 几乎全黑：98% 以上是 0，少量 1/2/3 |
| `near_white.bmp` | 50×34 | 几乎全白：98% 以上是 255，少量 248..253，宽高不是块数整数倍 |
| `flat.bmp` | 24×16 | 整幅一色 (88,96,104)：每通道只有一个非零桶 |

期望文件：`<名>.lut.csv`（global 三通道映射表，`--mode global --lut`）；`<名>.pixels.csv`（13 个采样
点在三种参数下的输入/输出值，按模式依次拼接，对应三次 `--probe`）；`clean.bg`、`noisy.bg`、
`near_white` 另有 `<名>.tiles.csv`（`--tiles 8 --clip 2.00` 下四个角块 (0,0)、(0,G-1)、(G-1,0)、
(G-1,G-1) 的每通道映射表）。
