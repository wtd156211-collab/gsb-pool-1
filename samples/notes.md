# 现场记录

（口径以 README 为准，这里只记现象。）

- 监控面板上有个计数一天涨了四十亿，其实设备一晚上只跑了三千次。翻记录才知道那晚停过电，设备重启、
  计数从零开始；面板拿两个数一减，得了个大得离谱的值，曲线直接炸成尖刺。
- 另一台设备是计数器满了自然回绕，面板把回绕那一跳算成负增量，图上掉了一根针。两种情形看起来
  都像「数字变小了」，靠得住的区分只有量程和归零这两个线索。
- 现场导出的采样不等间隔：设备忙的时候一分钟一条，闲的时候几个小时一条；导出按设备分块落在文件里，
  偶尔有两条样本的先后顺序跟时刻顺序对不上。
- 报表和页面各算各的，同一天同一台设备出过两个总增量。这次要求口径写死，谁算都是同一份结果。
- 有一条曲线整整一夜没有变化，值班的人以为采集挂了，其实是设备停了：零增量不该算异常。
- 运维希望页面上直接看到异常点落在哪里、每类异常有多少条，再决定要不要跑一趟现场。
